## Project Overview
An automated web-based platform designed to simplify lab equipment bookings, eliminate scheduling conflicts, and streamline returns for students, lecturers, technicians, and administrators.

## High-Level Features
* **User Authentication:** Multi-role access for Students, Lecturers, Technicians, and Admins.
* **Equipment Search & Filters:** Search lab items by name and view real-time availability.
* **Booking Workflows:** Automated request submissions and technician approval interfaces.
* **Return Tracking:** System logs for equipment check-outs and check-ins.
